# Қазақ туыстық ағашы · Дерево родства казахов

Интерактивная одностраничная веб-страница, наглядно показывающая **казахскую
систему родства** (туыстық жүйе) относительно центрального человека — «Мен» (ego).

Қазақ халқындағы туыстық атауларды «Менді» орталыққа қойып, тармақтап
көрсететін интерактивті сызба.

## Не бар / Что внутри

Родственные термины сгруппированы в ветви (тармақ):

- **Өрлеу — жеті ата** — семь поколений предков (әке → ата → баба → түп ата → …)
- **Ұрпақ — жеті буын** — семь поколений потомков (бала → немере → шөбере → шөпшек → …)
- **Ата-ана және ата-әже** — родители, деды и бабушки с обеих сторон
- **Бауырлар** — братья и сёстры (аға, іні, апа, қарындас, сіңлі)
- **Әке жағы — өз жұрты** — родня по отцу (аталас, немерелес)
- **Нағашы жұрт** — родня по матери (нағашы, жиен, бөле)
- **Қайын жұрт** — родня через брак (қайын ата/ене, балдыз, абысын, бажа, келін)
- **Құда-жекжат** — сватья

## Мүмкіндіктер / Возможности

- 🖱️ Клик по карточке раскрывает пояснение термина (кто это относительно «Мен»).
- 🔍 Поиск по любому термину (каз. / рус.).
- 🌙 Переключение светлой и тёмной темы (сохраняется в браузере).
- 📱 Адаптивная вёрстка для телефона и десктопа.

## Іске қосу / Как открыть

Зависимостей и сборки нет. Достаточно открыть файл в браузере:

```
index.html
```

Двойной клик по `index.html` — или перетащите его в окно браузера.

## Ескерту / Примечание

Термины родства могут слегка различаться по регионам и источникам (особенно
дальние поколения жеті ата и ұрпақ). Здесь приведён широко принятый вариант.
Это общеобразовательная схема, а не генеалогия конкретной семьи (шежіре).
